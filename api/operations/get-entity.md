# Get an entity

Returns one entity of the last build by its identifier, with its attributes, its displayed neighbourhood and the links it is an end of, as the [entity page](../../screens/entity-page.md) shows them. Declared by the OpenAPI contract of the [model query API](../model-query.md); nothing of it exists in the command line.

- [Entity page](../../screens/entity-page.md)
