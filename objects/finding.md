# Finding

The result of a check: a check identifier, a severity, a file and line when there is one, a message and a remediation, attached to an [entity](entity.md), a [link](link.md) or a [resource](resource.md). Findings go to the build log and the [model](model.md); the linter prints them in text, JSON, SARIF or JUnit. The [to-do page](../screens/todo-page.md) shows two of them as work lists.
