# Keyword page

An [entity](entity.md) the build creates for an expression that recurs above the publication threshold without a note: a term marked as a keyword, located on the first mention of its expression, carrying its occurrences, files and score as attributes and its passages in its fragment. It has a page at `keywords/<slug>`, enters the search index and the alphabetical index, and is listed on the to-do page as work to do; when a note defines the expression later, the address forwards to the note's page so that a link written to it survives.
