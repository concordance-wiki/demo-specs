# Finding

The result of a check: a check identifier, a severity, a file and line when there is one, a message and a remediation, attached to an [entity](../inference/entity.md), a [link](../inference/link.md) or a [resource](../ingestion/resource.md). Findings go to the build log and the [model](../inference/model.md); the linter prints them in text, JSON, SARIF or JUnit. The [to-do page](../../screens/pages/todo-page.md) shows two of them as work lists.
