# Stale source

A source or a note has not changed for longer than the configured threshold. The date comes from git and is always right.

Check `W-STALE`, severity warning by default, documented with a before and after example in the [check pages](https://github.com/concordance-wiki/concordance/blob/main/docs/checks/W-STALE.md). The severity can be overridden per project or per repository.
