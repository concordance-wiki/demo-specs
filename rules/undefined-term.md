# Undefined term

A recurring expression crosses the threshold without any note defining it. It has a keyword page built from its passages, but no definition.

Check `W-TERM-UNDEFINED`, severity warning by default, documented with a before and after example in the [check pages](https://github.com/concordance-wiki/concordance/blob/main/docs/checks/W-TERM-UNDEFINED.md). The severity can be overridden per project or per repository.
