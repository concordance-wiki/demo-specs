# Type conflict

The frontmatter `type` contradicts the type given by the file suffix. The tool reports rather than guesses.

Check `E-TYPE-CONFLICT`, severity error by default, documented with a before and after example in the [check pages](https://github.com/concordance-wiki/concordance/blob/main/docs/checks/E-TYPE-CONFLICT.md). The severity can be overridden per project or per repository.
