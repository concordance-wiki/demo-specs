# Missing application

An entity resolves to no application: none on the source, none in a rule, none in frontmatter.

Check `W-APP-MISSING`, severity warning by default, documented with a before and after example in the [check pages](https://github.com/concordance-wiki/concordance/blob/main/docs/checks/W-APP-MISSING.md). The severity can be overridden per project or per repository.

- [Entity](../objects/entity.md)
- [Build](../processes/build-pipeline.md)
- [Lint](../processes/lint.md)
