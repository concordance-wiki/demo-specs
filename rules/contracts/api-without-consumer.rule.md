# API without consumer

An API has no consumer, declared or inferred: no attribute, no section, no mention in another note.

Check `W-API-NOCONSUMER`, severity warning by default, documented with a before and after example in the [check pages](https://github.com/concordance-wiki/concordance/blob/main/docs/checks/W-API-NOCONSUMER.md). The severity can be overridden per project or per repository.
