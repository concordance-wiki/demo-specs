# Personal mention detected

A personal name was detected in a transcript outside the pseudonymisation dictionary. It is flagged for review before anything is published.

Check `I-PII-DETECTED`, severity info by default, documented with a before and after example in the [check pages](https://github.com/concordance-wiki/concordance/blob/main/docs/checks/I-PII-DETECTED.md). The severity can be overridden per project or per repository.
