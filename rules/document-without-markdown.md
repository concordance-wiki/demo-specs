# Document without markdown

A document has no markdown representation once the twin resources are reconciled: it stands as an entity of its own, or merged with other documents only. Its words are recorded from the text extracted from its PDF or its cues, but nobody wrote about it. The to-do page lists these documents; a note next to the document with the same base name, or declaring it under `source`, merges with it and lifts the finding.

Check `W-DOC-NOMD`, severity info by default, documented with a before and after example in the [check pages](https://github.com/concordance-wiki/concordance/blob/main/docs/checks/W-DOC-NOMD.md). The severity can be overridden per project or per repository.
